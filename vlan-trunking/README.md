# VLAN Trunking Lab

## Objective

Practice configuring VLANs and trunk links between Cisco switches.

## Devices

- 2 Cisco 2960 Switches
- 4 PCs

## VLAN

| VLAN | Name |
|------|------|
|10|Sales|
|20|HR|

## IP Address

| Device | IP |
|---------|------------|
|PC1|192.168.10.10|
|PC2|192.168.10.11|
|PC3|192.168.20.10|
|PC4|192.168.20.11|

## Verification

- VLAN created
- Trunk configured
- PCs in same VLAN communicate successfully
