# Cisco CCNA Labs

A collection of hands-on **Cisco networking labs** created using **Cisco Packet Tracer**.

This repository documents my learning and practice journey in computer networking, with a focus on **CCNA-level concepts, Cisco IOS configuration, network design, routing, switching, and troubleshooting**.

---

## 🎯 Purpose

The purpose of this repository is to:

- Practice networking concepts through hands-on labs
- Build practical Cisco IOS configuration skills
- Understand how network protocols and technologies work
- Develop troubleshooting and problem-solving skills
- Document my progress while studying CCNA
- Create a reference for future networking projects

---
